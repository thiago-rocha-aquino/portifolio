Sobre Mim

Olá! Sou um desenvolvedor de software focado em performance, usabilidade e código limpo. Trabalho de ponta a ponta no ciclo de desenvolvimento, desde a construção de interfaces dinâmicas (com React e Next.js) até o design e deploy de APIs robustas.

No back-end, meu foco é alinhar requisitos de negócios com decisões técnicas estruturadas. Em vez de apenas entregar código, busco analisar os trade-offs de cada abordagem, aplicando princípios de Domain-Driven Design (DDD) e Arquitetura Hexagonal para criar sistemas escaláveis e com domínio isolado. Minha stack principal inclui Python (FastAPI, SQLAlchemy) e Node.js, apoiada por bancos relacionais e NoSQL (PostgreSQL, MongoDB, Redis). Tenho forte vivência prática em toda a esteira da aplicação, unindo cultura DevOps (Docker, GitHub Actions) e automação para garantir estabilidade desde a concepção até o ambiente de produção em servidores Linux.
